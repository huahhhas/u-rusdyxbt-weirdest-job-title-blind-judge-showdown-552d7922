Entry for the [Weirdest Job Title: Blind Judge Showdown](https://make.fun/c/u-rusdyxbt-weirdest-job-title-blind-judge-showdown-552d7922) bounty on make.fun.

`main.py` (pure Python, standard library only) deterministically writes one original job title to `/output/entry.txt`:

> **Chief Apologizer for Elevators Stuck Between Floors**

A real-sounding job with one hilariously specific twist: a chief-level apologizer whose entire career is saying sorry on behalf of elevators that stop between floors.

Run it with:

```sh
python3 main.py
```
